# Заметки о пробелах шаблона Gridfin

Что мешало на проекте Secret Santa и что стоит улучшить в шаблоне: пробелы, неудобства, ошибки, лишнее и рекомендации. Дописываем по ходу работы, заказчица разбирает список отдельно.

Статус: **подтверждено** значит проверено в коде шаблона, **проверить** значит пока только предположение. Старт записей 2026-10-31. Проверено по `gridfin-template` версии 0.7.0, коммит `ddd5eae`.

| Дата | Пробел | Почему мешает | Что улучшить | Статус |
|---|---|---|---|---|
| 2026-10-31 | В модуле `persistence` есть только вход, регистрации нет | Для приложения с открытой регистрацией её приходится писать с нуля | Добавить регистрацию в `persistence` или отдельным модулем | подтверждено |
| 2026-10-31 | Нет подтверждения почты и сброса пароля | Вход с паролем без этого не готов для реальных людей | Добавить оба флоу | подтверждено |
| 2026-10-31 | Нет отправки писем | Нужна почти любому приложению с аккаунтами | Модуль `email` с единым интерфейсом и бесплатным вариантом для малых проектов | подтверждено |
| 2026-10-31 | Нет многоязычности в приложении, в `src` и `modules` ничего не найдено | Проект на пяти языках настраивает её сам | Модуль `i18n` | подтверждено |
| 2026-10-31 | Нет загрузки файлов и хранилища, в модулях только `persistence` и `observability` | Для фото нужно подключать своё решение | Модуль загрузки файлов | подтверждено |
| 2026-10-31 | Нет фоновых задач и рассылок по расписанию | Для рассылок и автоудаления данных нужно делать своё | Рецепт или модуль для заданий по расписанию | подтверждено |
| 2026-10-31 | Нет ролей и админки: seed создаёт обычного пользователя и отказывается работать в продакшене | Первого организатора в проде приходится определять своим способом | Роль администратора и понятный способ создать первого админа в проде | подтверждено |
| 2026-10-31 | Старт с готовой спекой | Быстрый старт идёт от идеи через `/gridfin`, неясно, как принять уже написанную спеку и существующую папку с `docs` | Описать путь «у меня уже есть спека» | проверить |
| 2026-10-31 | Ограничитель запросов живёт в памяти одного экземпляра | На Vercel он не защищает по-настоящему, это описано в коде, но решения нет | Вариант на базе без внешнего сервиса | подтверждено |
| 2026-10-31 | В `src/db/client.ts` `postgres(url)` без настроек для пула соединений | С пулом Neon могут ломаться подготовленные запросы | Настройки для бессерверного деплоя или переключатель, проверить на деплое | проверить |
| 2026-10-31 | `gh repo create --template` в README предполагает рабочий `gh` под нужным аккаунтом | При нескольких аккаунтах GitHub старт ломается | Описать запасной путь через SSH или кнопку на GitHub | подтверждено |
| 2026-10-31 | В Next 16 `middleware.ts` переименован в `proxy.ts`, а в `persistence` всё ещё `middleware.ts` | Работает, но с предупреждением об устаревании | Перейти на `proxy.ts` | проверить |
| 2026-10-31 | Вход через Google есть, но нет шага согласия и запрета регистрации для новых OAuth-пользователей | Если регистрация закрыта или нужно согласие, OAuth-вход это обходит | Хук `signIn` и страница согласия после первого входа | подтверждено |
| 2026-10-31 | Локальная папка называется `gridfin`, remote `grooownow/gridfin`, а в документации и спеке шаблон называется `gridfin-template` | Непонятно, один это шаблон или два разных | Одно имя везде | подтверждено |
| 2026-10-31 | Нет пути «начать из локальной копии шаблона без GitHub» | Мы работаем локально до одобрения, репозиторий создаём позже. Пришлось придумать `git archive HEAD \| tar -x -k` | Описать локальный старт в README | подтверждено |
| 2026-10-31 | Правило «навигация только через `<Link>`» не говорит о внешних ссылках | Для ссылок в новой вкладке нужен обычный `<a target="_blank" rel="noopener noreferrer">`, правило выглядит как запрет | Уточнить правило или дать компонент `ExternalLink` | проверить |
