# Пользовательское соглашение и согласие на обработку персональных данных

Действует с 7 августа 2026 года. Относится к странице gridfin на ludvik4.ru и к бета-программе продукта Gridfin.

## 1. Оператор

Оператор персональных данных — владелец сайта ludvik4.ru (далее — «оператор»). Связь с оператором: Telegram [t.me/ludvik4work](https://t.me/ludvik4work). Отправляя форму заявки и отмечая согласие, ты принимаешь это соглашение и даёшь согласие на обработку персональных данных в соответствии с Федеральным законом № 152-ФЗ «О персональных данных».

## 2. Какие данные обрабатываются

Только данные, которые ты вводишь в форму сам:

- GitHub username;
- email для обратной связи;
- профессиональная роль и опыт (необязательное поле);
- цель использования продукта.

Страница не использует cookies для отслеживания и не собирает данные автоматически.

## 3. Цели обработки

- предоставление доступа к бета-версии Gridfin (по GitHub username);
- связь по поводу доступа, обновлений беты и обратной связи (по email);
- понимание задач, для которых нужен продукт.

Правовое основание — твоё согласие (ст. 6 152-ФЗ). Данные не используются для рекламных рассылок и не продаются третьим лицам.

## 4. Как передаются и где обрабатываются данные

Заявка из формы поступает напрямую в приёмник на инфраструктуре Yandex Cloud и первично записывается на серверах, расположенных на территории Российской Федерации (требование локализации, ст. 18 152-ФЗ). Затем оператор получает уведомление о заявке на почтовый ящик российского почтового сервиса. Данные не передаются за пределы Российской Федерации.

## 5. Срок хранения и отзыв согласия

Данные хранятся, пока идёт бета-программа и поддержка выданных доступов. Согласие можно отозвать в любой момент — напиши в [t.me/ludvik4work](https://t.me/ludvik4work); данные будут удалены, доступ к бете при этом может быть прекращён. По этому же каналу можно запросить сведения о том, какие твои данные обрабатываются.

## 6. Условия беты

Gridfin в бете предоставляется «как есть»: возможны ошибки и изменения без предупреждения. Бета бесплатна; выданная в бете коробка остаётся у тебя вместе с будущими обновлениями. Оператор не гарантирует выдачу доступа по каждой заявке.

## 7. Изменения соглашения

Актуальная версия документа всегда доступна по этому адресу. При существенных изменениях условия беты для уже выданных доступов не ухудшаются.
