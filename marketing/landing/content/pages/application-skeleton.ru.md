# Что такое Application Skeleton в Gridfin

Application Skeleton — это заранее собранная архитектурная основа приложения для разработки с Claude Code. Он соединяет стек, структуру проекта, инженерные правила, тесты, гейты качества, skills и плейбуки в один рабочий процесс. Gridfin создаёт его в первый час работы — и дальше именно на этой основе агент строит твой продукт.

## Чем Application Skeleton отличается от boilerplate

- Boilerplate даёт готовый код: дашборд, биллинг, «50 фич под кастомизацию», из которых ты выпиливаешь лишнее.
- Application Skeleton даёт основу и процесс: тонкую архитектурную базу, в которой код растёт под конкретный продукт — через спеки, тесты и ревью.

Разница видна на двадцатой фиче: в boilerplate ты борешься с чужими решениями, в Skeleton — продолжаешь свой процесс.

## Что входит в Application Skeleton

- Next.js + TypeScript — основа приложения;
- Tailwind + shadcn/ui — дизайн-система и компоненты;
- инженерные правила (`docs/rules`) — архитектура, фронтенд, тестирование, безопасность, git;
- тесты — unit, компонентные, интеграционные и e2e, настроенные с первого дня;
- плейбуки — пошаговые сценарии деплоя, аналитики, pricing и других редких задач;
- skills — агентные workflows: онбординг, фичи, дизайн, ревью, верификация, деплой;
- hooks — правила с зубами: нарушение останавливается до записи кода;
- гейты качества — lint, тесты, e2e и сборка одним прогоном;
- механизм обновлений — `/update` подтягивает новые релизы шаблона, не затирая твой код.

## Как Claude Code работает внутри Skeleton

- Сначала спецификация: PRD и спека фичи пишутся до какого-либо кода.
- `/feature` ведёт каждую фичу по циклу спека → код → тесты → ревью.
- Тесты обязаны уметь падать: фича без честного теста не считается готовой.
- Ревью и гейты: красный статус виден до мержа, а не после релиза.

## Для кого это подходит

- У тебя есть идея и Claude Code, и ты готов работать с терминалом и git.
- У тебя нет многолетнего full-stack опыта — архитектурные решения уже приняты за тебя.
- Тебе нужен собственный настоящий репозиторий, а не no-code платформа.

## Где границы

- Стек фиксированный — Gridfin намеренно не конструктор «собери свой стек».
- Это не Lovable и не Bolt: работа идёт в терминале, через Claude Code.
- Это не готовый дашборд с 50 фичами — код растёт под твой продукт, а не наоборот.
