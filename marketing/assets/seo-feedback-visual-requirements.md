## Main Direction

The landing already explains Gridfin in text. The missing layer is product
visual proof: each large section should answer "what does this look like in
reality?" with a visual, not only with copy.

## Section Requirements

- `hero`: show a working Gridfin run, terminal, project structure, or minimal
  product diagram. Avoid abstract developer atmosphere.
- `problem`: keep the block mostly as-is; optional small pictograms for the
  four pains.
- `how-it-works`: use a vertical pipeline with real artifacts beside steps:
  specification snippet, project tree, green test output.
- `why-it-works`: add small engineering pictograms so cards scan faster.
- `what-you-get`: turn the list into a "box" / component set centered on
  Application Skeleton.
- `inside-gridfin`: add a new visual block between What you get and Trust.
  Show the `gridfin/` tree with callouts for rules, specs, tests, and workflow.
- `trust`: keep a human/process photo, but make it feel real and personal.
- `faq`: add category anchors for product, stack, pricing, Russia, beginners.
